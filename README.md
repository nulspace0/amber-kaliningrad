# 🟠 Янтарные Башни Калининграда

Аркадная игра-головоломка про строительство башен в пиксельном стиле, посвящённая **80-летию Калининградской области**. Игрок укладывает падающие янтарные блоки друг на друга, выстраивая восемь культурных достопримечательностей Калининграда — от Музея янтаря до новейшего филиала Большого театра.

## 🎮 Как играть

Блок движется слева направо над вершиной башни. Нажмите (кликом или касанием), чтобы уложить его. Чем точнее блок ложится на предыдущий, тем устойчивее растёт башня — выступающие края отсекаются, и площадка становится уже.

- Точные укладки дают эффектные искры (а идеальные — особенно щедрые).
- Промах сужает башню; **три промаха** — и постройка обрушивается, текущее здание начинается заново.
- Когда здание достроено, блоки растворяются, проявляя настоящий облик достопримечательности, и открывается карточка с историческими фактами.
- Соберите все **8 зданий**, чтобы увидеть финал: «Калининград построен!».

## 🏛️ Достопримечательности

Каждое здание сопровождается реальной исторической справкой:

1. **Музей янтаря** — единственный в мире, в башне Дона
2. **Кафедральный собор** — готика XIV–XV веков, мавзолей Иммануила Канта
3. **Драматический театр** — символ возрождения послевоенного города
4. **Дом искусств** — советский конструктивизм
5. **Музей Мирового океана** — корпус-глобус «Планета Океан»
6. **Филиал РГИСИ** — первый театральный вуз региона
7. **Филиал Третьяковской галереи** — самый западный филиал галереи
8. **Филиал Большого театра** — проект бюро Snøhetta

## ✨ Особенности

- 🎨 Пиксельная графика с закатным балтийским фоном, облаками, волнами и летающими чайками
- 🔊 Динамическое звуковое окружение: фоновая музыка, шум моря и крики чаек, которые мягко появляются и затихают, плюс отдельная финальная мелодия
- 📱 Адаптивно под мобильные устройства — поддержка касаний и масштабирование под экран
- 📚 Образовательная составляющая: каждое здание знакомит с архитектурой и историей края
- ⚡ Без зависимостей — чистый HTML5 Canvas, CSS и JavaScript в одном файле

## 🚀 Запуск

Локально достаточно открыть `index.html` в браузере. Для корректной загрузки звуков и изображений лучше запустить простой локальный сервер:

```bash
# Python 3
python -m http.server 8000
# затем откройте http://localhost:8000
```
